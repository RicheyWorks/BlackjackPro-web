# Blackjack Pro

Browser port of [RicheyWorks/BlackJackPro](https://github.com/RicheyWorks/BlackJackPro). Six-deck shoe, 3:2 naturals, American peek, late surrender, even money, splits to four hands, optional 21+3, Hi-Lo coach.

See `SECURITY.md` for the cash and persist hardening notes.

```bash
npm install
npm test
npm run dev
```
